1. COMPLETE PROJECT IDEA
==================================================

We are building an AI-powered university assistant that helps students access academic and administrative information.

Students should be able to:

1. Ask questions in Arabic, French, or English.
2. Receive answers based on official university documents.
3. Search university announcements.
4. Find campus facilities.
5. View sources used by the AI.
6. Access information through a modern web interface.

The application contains:

- React frontend.
- FastAPI backend.
- LangGraph AI Agent.
- RAG pipeline.
- PostgreSQL with pgvector.
- University documents.
- Authorized announcements.
- Campus location information.
- Huawei Cloud deployment.

The application must not invent university information.

The frontend must clearly display unavailable information and API errors.

7. SHARED API CONTRACT
==================================================

The frontend must use the agreed backend API.

----------------------------------------
CHAT
----------------------------------------

Endpoint:

POST /api/v1/chat

Request:

{
    "message": "What documents are required for university registration?",
    "language": "en",
    "conversation_id": null
}

Response:

{
    "conversation_id": "example-conversation-id",
    "answer": "Grounded answer",
    "language": "en",
    "sources": [
        {
            "source_id": "doc-001",
            "title": "University Registration Guide",
            "source_type": "document",
            "page": 3,
            "url": null
        }
    ],
    "status": "answered"
}

These are example values.

Possible status values:

- answered
- not_found
- error

Use the agreed schema.

Do not rename fields independently.

----------------------------------------
ANNOUNCEMENTS
----------------------------------------

Endpoint:

GET /api/v1/announcements

Query parameters:

- q
- category
- limit

Response:

{
    "items": [
        {
            "id": "announcement-001",
            "title": "Example announcement",
            "content": "Example content",
            "published_at": "2026-11-01T10:00:00Z",
            "source_url": "https://example.edu/announcement",
            "category": "administrative"
        }
    ]
}

These are placeholders.

----------------------------------------
CAMPUS LOCATIONS
----------------------------------------

Endpoint:

GET /api/v1/locations

Response:

{
    "items": [
        {
            "id": "location-001",
            "name": "Example Faculty",
            "description": "Example facility",
            "latitude": 0.0,
            "longitude": 0.0,
            "category": "faculty"
        }
    ]
}

The coordinates are placeholders.

Do not use them as real locations.
